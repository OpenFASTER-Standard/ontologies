# XSD Ontology (`XSDO:`)

Part of [OpenFASTER Ontologies](../README.md). An OWL vocabulary for XML
Schema 1.1's abstract Schema Component Model (element/attribute
declarations, complex/simple type definitions, particles, facets).

**Status: skeleton only, no classes curated yet.**

Hand-edit `src/xsd-edit.ofn` directly (OWL Functional Syntax, diff-friendly
— never machine-round-tripped). Build/verify with
`../scripts/build-module.sh xsd xsd xsd-ontology` from the repo root.
