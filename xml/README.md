# XML Ontology (`XMLO:`)

Part of [OpenFASTER Ontologies](../README.md). An OWL vocabulary for a
concrete XML document instance's actual structure -- as opposed to
`xsd/`'s grammar of what's allowed.

**Status: skeleton only, no classes curated yet.**

Hand-edit `src/xml-edit.ofn` directly (OWL Functional Syntax, diff-friendly
— never machine-round-tripped). Build/verify with
`../scripts/build-module.sh xml xml xml-ontology` from the repo root.
